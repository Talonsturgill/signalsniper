## Pick: Archon by Cole Medin (@cole_medin)

URL https://github.com/coleam00/Archon

### Defense paragraph (saved for Agent 9)

Archon treats AI coding the way Docker treated infra: as code. Cole rewrote it from Python to TypeScript on April 7 and the project has been climbing GitHub trending since, picking up roughly 450 stars a day. The pitch is direct. AI coding agents are non-deterministic by default; Archon makes them repeatable by letting you define planning, implementation, validation, and review as YAML DAG workflows that run identically across projects. It speaks MCP natively so any harness you build plugs into Claude Code, Cursor, or Windsurf. This is builder-tier infrastructure shipped by an individual, not a frontier lab, and it sits exactly where adversarial agent loops, MCP tooling, and deterministic deployment meet. The novelty is not the agent, it is the harness. Worth a tribute.

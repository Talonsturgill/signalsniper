## What Superpowers actually does
- Composable skills framework + opinionated dev methodology that ships as a plugin for Claude Code (also OpenCode, Cursor, Copilot, Gemini setups).
- Skills are markdown files the agent is forced to load and follow. Forcing functions, not suggestions.
- Enforces brainstorm -> design -> plan -> implement workflow before code.
- Bundled skills cover TDD (red-green-refactor, tests must fail first), four-phase systematic debugging, brainstorming/planning/code-review, subagent-driven development with two-stage review.
- Uses git worktrees to give subagents isolated workspaces for parallel work.
- Includes meta-skills so the agent can author and refine new skills (self-compounding knowledge system).

# This Week in AI · The Shell Script That Crossed 42,000 Stars

*Issue 6 · June 7 to June 13, 2026 · ~7 min read*

Five repos made the shortlist, and the one that ran away with it isn't a framework at all. It's a folder of plain text rules wired together by a shell script. ## The All-Star · taste-skill by @LexnLin

On June 7, taste-skill sat first on GitHub's trending page while every other agent skill trailed behind. The repo had crossed 35,000 stars on its way to a count most two-year-old projects never reach. What earned it the All-Star slot wasn't size, though. It was the claim underneath. Leon Lin argues that coding models drift toward generic output because they're probability machines, and the fix isn't more imagination, it's fewer choices. He encoded that into rules an agent loads before it writes a line of UI.

What it does is narrow the agent's hand. taste-skill drops a set of rule sheets into Cursor, Claude Code, Codex and five other tools, each a strict SKILL.md governing layout, typography, motion and spacing, with three dials for variance, motion and density. There's no runtime and no model of its own. A shell registry maps the rule files and the agent loads them on demand.

Lin has been bending coding agents for a while. His agentic-ai-prompt-research repo, which reverse-engineered how assistants get steered, sits near 2,400 stars, and smaller tools like prompt-library and todobar show the same habit of shipping sharp, opinionated artifacts. taste-skill points that instinct at output instead of input.

The week moved fast. The repo climbed from roughly 35,800 stars to 42,647, a gain of 6,847 in six days, while forks crossed 2,900. It spun off brutalist, minimalist and image-to-code variants, and on June 12 it added a plugin manifest so it installs straight from the VS Code marketplace. Most projects that size are years old. This one is barely four months past its first commit, and it's still marked experimental on the default skill.

> Less slop, designs pop.

That's the pitch on the project site, and the repo is the argument that taste can be written down rather than hoped for. [Read it](https://www.tasteskill.dev/).

## The pattern this week

The repos that climbed this week stayed thin and stood on tools that already worked. @Neo_Reidlab's Agent-Reach doesn't wrap the open web behind a new API, it shells out to command-line tools engineers already trust and keeps them patched as sites change. @wesmckinn's agentsview doesn't ask agents to log anything new, it reads the JSONL they already emit and indexes it in one Go binary. @evalstate's fast-agent treats the Model Context Protocol as the architecture instead of a connector, then ships point releases almost daily. Each builder bet that the durable edge is in restraint, not abstraction. @francedot's cua is the exception that proves it, because giving agents a sandboxed machine took real new infrastructure and drew a crowd anyway.

## The lesson this week · Ship against an interface the agent already understands

Pattern is one thing, here's the move you can copy. Pick the interface your users' agents already speak, then meet it instead of minting your own. Leon Lin didn't build a design engine, he wrote SKILL.md files, the exact format Cursor and Claude Code already read on startup. Neo Reid didn't author fourteen fresh clients, he wrapped gh, yt-dlp and Jina Reader behind one command and kept them working as the sites underneath shifted. Shaun Smith didn't define a protocol, he conformed to MCP and let every compliant client talk to his agent for nothing.

The shared trick is a thin adapter over a contract that already exists.

```bash
declare -A SKILLS=(
[taste-skill]="skills/taste-skill/SKILL.md"
[brutalist-skill]="skills/brutalist-skill/SKILL.md"
)
```

That registry is the whole integration surface, and it's under ten lines of shell. Reach for this approach when an agent or a spec already defines the slot you'd fill, because matching it buys instant distribution to everyone already on that contract. Reach for a brand-new abstraction only when nothing else fits, and go in knowing you'll carry the adoption cost by yourself.

## Code from the week

Install taste-skill into any of eight coding agents.

```bash
npx skills add Leonxlnx/taste-skill
```

Agent-Reach probes every channel and prints the active backend before it runs.

```bash
$ agent-reach doctor

Agent Reach Status
========================================
Ready to use:
  GitHub repos and code -- public repos readable and searchable
  YouTube video subtitles -- yt-dlp
  RSS/Atom feeds -- feedparser
  Web pages (any URL) -- Jina Reader API
```

fast-agent composes an MCP-backed agent into a chain workflow.

```python
@fast.agent(
    "url_fetcher",
    instruction="Given a URL, provide a complete and comprehensive summary",
    servers=["fetch"],
)
@fast.chain(
    name="post_writer",
    sequence=["url_fetcher", "social_media"],
    default=True,
)
```

agentsview reports cost straight from its local index.

```bash
agentsview usage daily --breakdown
agentsview usage daily --agent claude --since 2026-04-01
```

cua runs one agent loop over a swappable, ephemeral sandbox.

```python
import asyncio
from cua import Sandbox, Image, ComputerAgent

async def main():
    async with Sandbox.ephemeral(Image.linux()) as sb:
        agent = ComputerAgent(model="cua/anthropic/claude-sonnet-4.5", tools=[sb])
        async for result in agent.run([{"role": "user", "content": "Take a screenshot"}]):
            print(result)

asyncio.run(main())
```

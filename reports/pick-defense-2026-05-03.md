# Pick: Agent Safehouse by Eugene (@eugene1g)

URL: https://github.com/eugene1g/agent-safehouse

## Why this one today

Eugene shipped the sandbox primitive everyone deploying coding agents has been hand-rolling. A single-script, deny-first kernel sandbox via macOS sandbox-exec that wraps Claude Code, Codex, Gemini CLI, Cursor Agent, Cline, and Aider in one config. 823 HN points in 24 hours because builders recognized it as the security layer they had been hacking around. It hits the secure AI deployment lane exactly. No model claims, no framework, just a tight wrapper around an underused OS primitive that turns "I let an agent run loose on my laptop" from terrifying to acceptable.

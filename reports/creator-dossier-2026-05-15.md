# Creator dossier — 2026-05-15

## Project

- **Repo**: `NousResearch/hermes-agent`
- **URL**: https://github.com/NousResearch/hermes-agent
- **What it is**: An open-source AI agent with a built-in learning loop. The agent creates skills from experience, improves them during use, persists memory across sessions, and builds a deepening model of the user across runs. Runs on any infrastructure from a $5 VPS to serverless. Multi-platform: CLI, Telegram, Discord, Slack, WhatsApp, Signal, web TUI.
- **One-line**: The agent that grows with you.
- **License**: MIT

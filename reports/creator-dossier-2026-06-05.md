# Creator dossier — 2026-06-05

## Project
**boxes.dev** — a cloud agentic development environment (ADE). Every Claude Code or
Codex agent gets its own computer in the cloud (a "box", internally a "fork"): a real
Linux machine with its own filesystem, port-forwarding back to your localhost, and your
dev environment preinstalled. You connect from desktop and mobile, run agents in
parallel, and use your own Claude / Codex subscription. The pitch is "ditch localhost":
instead of juggling git worktrees and starving one laptop's CPU across N agents, each
agent runs isolated on its own warm machine.

- Project URL: https://boxes.dev
- Launch surfaces: Show HN (2026-06-04, ~89 points, ~64 comments) and Product Hunt
  (launch week of 2026-06-05, ranked ~#13 for the day, ~107 upvotes).
- Category: builder-tier infrastructure / agentic-coding patterns / sandboxed isolation.

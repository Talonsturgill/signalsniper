## Project

- **Repo**: `santifer/career-ops`
- **URL**: https://github.com/santifer/career-ops
- **What it is**: An AI-powered job-search system built on Claude Code that turns any AI coding CLI into a job-search command center. It scores job offers with structured A-to-F grading across 10 weighted dimensions, generates ATS-optimized tailored CVs/PDFs per offer, scans career portals with Playwright, and batch-processes evaluations with parallel sub-agents. It is explicitly human-in-the-loop — the AI analyzes and recommends, the user decides, and it never auto-submits an application.

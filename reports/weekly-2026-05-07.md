## The All-Star · Needle by @hmunachii

*Skip this section unless you're shipping on-device agents that need to call tools without a network connection.*

Henry Ndubuaku pushed commits b4a4d5b and 375a4a0 on the morning of May 13, the same hour Needle hit the top of Hacker News at 444 points. One updated model configs. The other fixed a tokenizer bug on a model already running in people's projects. By the time the thread reached 627 points and 179 comments, two community contributors had merged separate PRs: Python 3.14 compatibility plus a ToolConstraints fix. A model built in 27 hours had four patches on its first day.

Needle is a 26-million-parameter Simple Attention Network distilled from Gemini 3.1. No feedforward layers, only attention. That single structural choice means the model compiles down to matrix multiplications every mobile NPU already handles. Google's closest competitor, FunctionGemma, is 270 million parameters, ten times larger. Needle's own benchmarks claim better single-shot function call accuracy despite the size gap. The README says the model is bad at conversation. That's the point.

I think Needle matters because Henry shipped Cactus (4.8k stars) first: a low-latency mobile inference engine for phones, watches, and glasses. Cactus is the product. Needle is the research artifact that justifies it. He also maintains a Maths-CS-AI Compendium (3.7k stars) and has four ICLR papers on quantization, mobile optimization, and efficient architectures. The HN thread confirmed what the dossier suggested: ML practitioners who ran no-FFN experiments found the same result. Commenter kgeist noted similar findings from Qwen work. Commenter efskap called it "Attention Is ACTUALLY All You Need." Stars climbed from 795 to 1,300 in under 18 hours.

> "Needle doesn't compete with those tools though and the distillation process did not access the weights."

## The pattern this week

@jundotkim's oMLX added a tiered SSD KV cache that survives restarts, pushing decode speed from 8.65 to 22.66 tokens per second. @senamakel's OpenHuman jumped from 1.9k to 5.3k stars in 36 hours, partly because its memory tree stores in Obsidian-readable markdown: auditable by the user, not just the agent. @hmunachii's Needle strips all feedforward layers from a 26-million-parameter model so the remaining attention blocks compile cleanly to mobile NPU GEMMs. Three layers (inference, memory, model weights), three concrete constraints solved. What I keep coming back to is that none of the three has published a benchmark showing on-device parity with a cloud model on the same task, so the threshold crossed is size and persistence, not yet capability.

## Code from the week

One revealing snippet per project, chosen for what it shows about the design.

### proofshot: the record/stop lifecycle

ProofShot wraps `agent-browser` with timestamped capture so every browser action gets bundled into a proof artifact with compact element refs.

```bash
# Open browser, begin recording, capture server logs
proofshot start --run "npm run dev" --port 3000 --description "Login form verification"

# Agent drives the browser using compact element refs
agent-browser open http://localhost:3000/login
agent-browser fill @e2 "test@example.com"
agent-browser click @e5
agent-browser screenshot ./proofshot-artifacts/step-login.png

# Bundle video, screenshots, errors into one proof artifact
proofshot stop
```

### react-doctor: the agent skill install

One install command writes agent-aware rule files for Claude Code, Cursor, Codex, and 50+ other coding agents so they generate idiomatic React by default.

```bash
# Install as a coding agent skill (auto-detects which agents are present)
npx -y react-doctor@latest install

# Skip prompts, write rules for all detected agents immediately
npx -y react-doctor@latest install --yes

# Run a one-shot health scan of your codebase (returns a 0 to 100 score)
npx -y react-doctor@latest .
```

### oMLX: the tiered KV cache config

Hot blocks stay in RAM, cold blocks spill to SSD in safetensors format, and the prefix cache rebuilds on matching prefix across server restarts.

```bash
omlx serve --model-dir ~/models \
  --paged-ssd-cache-dir ~/.omlx/cache \
  --hot-cache-max-size 20% \
  --max-model-memory 32GB \
  --max-concurrent-requests 16 \
  --api-key your-secret-key
```

### OpenHuman: the global memory client

The memory client bootstraps asynchronously from the workspace config directory, giving every CLI subcommand a single shared reference backed by SQLite.

```rust
async fn create_memory_client() -> Result<crate::openhuman::memory::MemoryClientRef> {
    let config = crate::openhuman::config::Config::load_or_init()
        .await
        .unwrap_or_default();
    crate::openhuman::memory::global::init(config.workspace_dir)
        .map_err(anyhow::Error::msg)
}
```

### Needle: the 26M attention-only inference

Load the checkpoint, call generate with a tool schema, get a function call back. No feedforward layers, 12 encoder plus 8 decoder.

```python
from needle import SimpleAttentionNetwork, load_checkpoint, generate, get_tokenizer

params, config = load_checkpoint("checkpoints/needle.pkl")
model = SimpleAttentionNetwork(config)  # 12 encoder + 8 decoder layers, no FFN
tokenizer = get_tokenizer()

result = generate(
    model, params, tokenizer,
    query="What's the weather in San Francisco?",
    tools='[{"name":"get_weather","parameters":{"location":"string"}}]',
    stream=False,
)
```

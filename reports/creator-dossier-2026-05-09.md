## What it actually ships

ProofShot is an open-source CLI you install once, then any AI coding agent can call it as a verification step:

- **Records browser sessions** as video while the agent's code runs
- **Captures screenshots** at key moments
- **Collects console + server errors** across 10+ programming languages
- **Bundles proof artifacts** into an interactive HTML viewer with video playback
- **Integrates with GitHub PRs** so the verification report attaches to the diff

Install: `npm install -g proofshot && proofshot install`

Compatible agent runners: Claude Code, Cursor, Codex (OpenAI), OpenCode, Gemini CLI, Windsurf, GitHub Copilot.
